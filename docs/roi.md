# ROI 1쪽 — 금융 약관 QA 에이전트, 한 달에 얼마이고 무엇을 아끼는가

> 규칙 둘. **측정값과 가정값을 구분한다.** 측정값에는 파일 이름을, 가정값에는 "가정"이라고 적는다.
> 숫자는 `make roi` 가 찍어 준다. 가정을 바꾸고 싶으면 `python scripts/roi.py --daily 2000` 처럼 돌린다.

작성 2026-10-12  |  기준 결과 파일 `results/agentic.json` (40문항, 모델 **fake** — 아래 "읽기 전에" 참고)

> **읽기 전에.** 5회차 `make agentic` 을 돌릴 때 OpenAI 키가 401(invalid_api_key)로 거부되어 결과 파일이
> 가짜 모델(`"llm": "fake"`)로 만들어졌다. 가짜 모델은 토큰을 쓰지 않아 `usage` 가 없고, `make roi` 는
> "결과 행에 usage 가 없습니다"로 멈춘다. 그래서 **1절의 토큰·비용은 미측정이다.** 지연은 측정값이지만
> LLM 호출 시간이 0 인 값이라 실제보다 작다. 키가 활성화되면 `make agentic`(12분) → `make roi` 순으로
> 돌려 1·3·4·5절의 "미측정" 칸을 채운다. 이 문서의 나머지(가정값, 계산식, 손익분기 구조)는 그대로 쓴다.

## 1. 측정값 — 문항 하나가 얼마인가

| 항목 | 값 | 출처 |
|---|---|---|
| 문항당 입력 토큰 | 미측정 (usage 없음) | `results/agentic.json` usage, `make roi` |
| 문항당 출력 토큰 | 미측정 (usage 없음) | 같음 |
| 문항당 비용 | 미측정원 ($미측정) | 단가 기준일 2026-10 (`cost.PRICES_USD_PER_M`: mini 입력 0.75 · 캐시 0.075 · 출력 4.50, nano 입력 0.20 · 캐시 0.02 · 출력 1.25 USD/1M) |
| 재검색한 문항 비율 | 미측정 (가짜 모델은 항상 sufficient 판정이라 재검색 0회) | `retry_count > 0` |
| 문항당 지연(평균 / p95) | 18.2초 / 23.8초 (가짜 모델. LLM 시간 0 포함) | `latency_ms_avg` 18177.7, `latency_ms_p95` 23841.2 |

검색(임베딩·BM25·리랭커)은 로컬이라 API 비용이 0 이다. 돈은 LLM 호출에만 든다. 어느 호출이 큰지 한 줄: 측정 전 예상은 **답변을 만드는 gpt-5.4-mini 의 출력 토큰**이다. 단가표에서 mini 출력(4.50)이 입력(0.75)의 6배, nano 출력(1.25)의 3.6배라 같은 토큰 수라도 답변 생성이 비용의 대부분을 차지한다. 필터 추출·판정은 nano 로 돌고 출력이 JSON 몇 줄이라 작다. 4회차 hybrid 의 문항당 지연이 1.3초(`results/hybrid.json` latency_ms_avg 1311)였으니, 실제 키로 돌린 agentic 지연에서 1.3초를 빼면 그 차이가 LLM 몫이다.

## 4. 외부 API 안 vs 내부망 GPU 안 (3년 TCO)

| 안 | 3년 비용 | 구성 | 얻는 것 / 잃는 것 |
|---|---|---|---|
| 외부 API | 10,800,000원 + API 36개월분 (미측정) | API 미측정원 × 36 + 서버 300,000 × 36 | 초기 투자 0, 모델 교체 쉬움 / 질문이 망 밖으로 나간다(마스킹 필수) |
| 내부망 GPU | 53,800,000원 | 구매 25,000,000원 + 운영 6,000,000원 × 3 + 서버 300,000 × 36 | 망 안에서 끝난다 / 초기 투자, 작은 모델의 품질 |

손익이 뒤집히는 일 질문 수: 약 미측정건 (선형 가정. `make roi` 가 `breakeven_daily_questions` 로 찍는다). 지금 가정(일 500건)에서는 외부 API 안이 3년에 미측정원 싸다. 구조만 미리 보면, GPU 안 3년 5,380만 원에서 서버비 1,080만 원을 뺀 4,300만 원을 API 로 쓰려면 월 약 119만 원, 문항당 약 109원($0.078)이 나와야 한다. mini 출력 단가로 환산하면 문항당 출력 1만 7천 토큰에 해당하므로, 실제 측정값이 그보다 한참 작으면 API 안이 싸다.

## 6. 이 숫자를 믿기 전에 (3줄)

1. 5절의 절감 1,375만 원은 전부 가정에서 나왔다. "건당 3분 절감"과 "일 500건"은 측정하지 않았다. 둘 중 하나가 반이 되면 절감도 반이 된다. 1회차 디스커버리 노트의 현재 처리 시간과 상담 건수로 바꾸기 전에는 이 숫자를 밖에 내지 않는다.
2. 오거절률만큼은 상담사가 다시 봐야 하므로 절감에서 빼야 한다. 지금 `results/agentic.json` 의 `false_refusal_rate` 는 0.0 이지만 가짜 모델이 모든 문항에 답한 결과라 믿을 수 없다. 반대로 미답변 정확도 0.0 은 거절해야 할 2문항에 숫자를 만들어 답했다는 뜻이고, 이런 답은 절감이 아니라 사고 비용이다. 실제 키로 다시 재서 두 값이 나오면 절감에 (1 − 오거절률)을 곱하고, 미답변 오답 건수는 별도 위험 비용으로 적는다.
3. 1절의 비용은 아직 미측정이고, 단가는 2026년 10월 `cost.PRICES_USD_PER_M` 기준이라 바뀐다. 4절의 손익분기(문항당 약 109원)는 단가와 환율 1,400원에 따라 움직이므로 분기마다 `make roi` 를 다시 돌려 이 문서의 숫자를 갱신한다.
