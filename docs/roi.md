> 규칙 둘. **측정값과 가정값을 구분한다.** 측정값에는 파일 이름을, 가정값에는 "가정"이라고 적는다.
> 숫자는 `make roi` 가 찍어 준다. 가정을 바꾸고 싶으면 `python scripts/roi.py --daily 2000` 처럼 돌린다.

작성 2026-10-13  |  기준 결과 파일 `results/agentic.json` (40문항, 모델 openai:gpt-5.4-mini + gpt-5.4-nano, 2026-10-13 실행)

## 1. 측정값 — 문항 하나가 얼마인가

| 항목 | 값 | 출처 |
|---|---|---|
| 문항당 입력 토큰 | 11,845 (nano 6,851 + mini 4,994) | `results/agentic.json` usage, `make roi` |
| 문항당 출력 토큰 | 551 (nano 346 + mini 206) | 같음 |
| 문항당 비용 | 8.7원 ($0.00624), 최대 17원 | 단가 기준일 2026-10-08 (`cost.PRICES_USD_PER_M`: mini 입력 0.75 · 출력 4.50, nano 입력 0.20 · 출력 1.25 USD/1M) |
| 재검색한 문항 비율 | 30% (12/40) | `retry_count > 0` |
| 문항당 지연(평균 / p95) | 11.8초 / 22.6초 | `latency_ms_avg` 11821.3, `latency_ms_p95` 22601.4 |

검색(임베딩·BM25·리랭커)은 로컬이라 API 비용이 0 이다. 돈은 LLM 호출에만 든다. 어느 호출이 큰지 한 줄: **답변을 만드는 mini 의 입력 토큰**이 가장 크다. 모델별로 단가를 곱하면 mini 가 문항당 약 $0.0047(입력 $0.0037 + 출력 $0.0009)로 전체의 약 72%, nano 는 약 $0.0018 이다. 출력 단가가 6배 비싸도 출력은 206토큰뿐이고, 리랭크한 청크 8개를 통째로 넣는 입력이 5천 토큰이라 입력이 더 비싸다. 비용을 줄이려면 출력을 짧게 하는 것보다 답변 모델에 넣는 청크 수·길이를 줄이는 쪽이 효과가 크다. 지연은 4회차 hybrid 1.3초(`results/hybrid.json`)에서 11.8초로 늘었고, 차이 10.5초가 LLM 호출(재작성·필터·판정·답변)과 재검색의 몫이다.

## 4. 외부 API 안 vs 내부망 GPU 안 (3년 TCO)

| 안 | 3년 비용 | 구성 | 얻는 것 / 잃는 것 |
|---|---|---|---|
| 외부 API | 14,257,800원 | API 96,050원 × 36 + 서버 300,000 × 36 | 초기 투자 0, 모델 교체 쉬움 / 질문이 망 밖으로 나간다(마스킹 필수) |
| 내부망 GPU | 53,800,000원 | 구매 25,000,000원 + 운영 6,000,000원 × 3 + 서버 300,000 × 36 | 망 안에서 끝난다 / 초기 투자, 작은 모델의 품질 |

손익이 뒤집히는 일 질문 수: 약 1,887건 (선형 가정). 지금 가정(일 500건)에서는 외부 API 안이 3년에 39,542,200원 싸다. 하루 질문이 지금의 3.8배가 되기 전에는 GPU 를 살 이유가 비용에는 없다. GPU 안을 고를 이유가 있다면 비용이 아니라 "질문이 망 밖으로 나가면 안 된다"는 보안 요건이고, 그 경우 3년 3,950만 원이 그 요건의 가격이다.

## 6. 이 숫자를 믿기 전에 (3줄)

1. 5절의 절감 1,375만 원은 전부 가정에서 나왔다. "건당 3분 절감"과 "일 500건"은 측정하지 않았다. 둘 중 하나가 반이 되면 절감도 반이 된다. 비용(월 39.6만 원)은 측정에 가깝지만 절감은 가정이라, 순 효과 1,335만 원은 자릿수만 믿고 숫자는 믿지 않는다. 1회차 디스커버리 노트의 현재 처리 시간과 상담 건수로 바꾸기 전에는 밖에 내지 않는다.
2. 오거절률 5.3%(`results/agentic.json` false_refusal_rate 0.0526, 답할 수 있는 38문항 중 2건 거절)만큼은 상담사가 다시 보므로 절감에서 뺀다. 그보다 큰 구멍은 **답했지만 틀린 것**이다. judge 20문항 평균 3.74/6 이고 0점이 3문항(S05·S20·S22)이다. 틀린 답은 절감이 아니라 사고 비용인데 이 표에는 그 항이 없다. 미답변 정확도는 1.0(거절해야 할 2문항 모두 한계를 밝힘)이라 그쪽 위험은 작다.
3. 문항당 8.7원은 2026-10-08 단가와 환율 1,400원 기준이고 바뀐다. 다만 월 비용의 76%가 서버라 LLM 단가가 2배가 되어도 월 비용은 24% 오르는 데 그친다. 반대로 지연 p95 22.6초는 상담 화면에 쓰기엔 길다. 7회차 `/ask` API 의 응답 예산을 잡을 때 이 값이 출발점이고, 재검색 상한(30%가 재검색)을 낮추면 비용과 지연이 함께 내려간다.
